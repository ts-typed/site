# TypeScript: introdução

TS Typed preserva contratos TypeScript em runtime, especialmente em fronteiras que recebem JSON, arquivos, filas ou outros serviços.

Escreva uma interface ou classe, tipa o parâmetro ou retorno e compile com TS Typed. A ferramenta adiciona verificações sem mudar a forma de escrever TypeScript. Veja [Conceitos centrais](../core-concepts.md).
