# TypeScript: getting started

Use this path for a library, worker, CLI, or application that already compiles with `tsc`.

```bash
npm install --save-dev @ts-typed/core
npx ts-typed init
npx ts-typed build
```

Run the emitted JavaScript from `outDir`, not the original source. The `init` command creates `typets.config.json`; use [Configuration](./configuration.md) to review its confirmed keys. The CLI command list beyond `init` and `build` is pending final factual review.
