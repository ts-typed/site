# TypeScript: introduction

TS Typed preserves TypeScript contracts at runtime. It is especially useful at boundaries where data comes from JSON, a file, a queue, or another service.

Types remain the source of truth: write an interface or class, type the function parameter or return, and build with TS Typed. The compiler adds checks to typed boundaries while preserving ordinary TypeScript authoring. See [Core Concepts](../core-concepts.md) for closed objects and error codes.
