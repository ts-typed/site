# TypeScript: configuration

Keep `typets.config.json` at the project root. Start with `npx ts-typed init`, then set only options documented by the installed compiler version. `outDir` selects the emitted, instrumented JavaScript directory.

Compile with the normal TypeScript program and run the output. Do not copy framework-specific scripts into a plain TypeScript project. For contract semantics, see [Core Concepts](../core-concepts.md); for confirmed option names and defaults, use the global [Configuration](../configuration.md).
