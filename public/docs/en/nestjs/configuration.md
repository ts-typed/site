# NestJS: configuration

Nest uses `typets.config.json` at the project root. `npx ts-typed init` creates the starting file; [Configuration](../configuration.md) explains shared keys such as `outDir`.

Keep the Nest compiler program and decorators in the emitted build. SWC, webpack, and other alternate builders need a separate factual verification before being documented as supported. This guide intentionally states no unconfirmed CLI flags.
